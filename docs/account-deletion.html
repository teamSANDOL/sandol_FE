산돌이 계정 삭제 요청

운영: teamSANDOL(산돌이 개발팀)

산돌이 앱 계정과 관련 데이터는 아래 두 가지 방법 중 하나로 삭제할 수 있습니다. 어느 쪽이든 삭제되는 데이터와 처리 기간은 같습니다.

방법 1. 앱에서 직접 삭제 (즉시 처리)

  1. 산돌이 앱에 로그인합니다.
  2. 홈 화면 오른쪽 위 프로필 아이콘을 눌러 마이페이지로 이동합니다.
  3. 화면 맨 아래 회원 탈퇴를 누르고 확인합니다.

확인 즉시 계정이 삭제되고 앱에서 로그아웃됩니다.

방법 2. 웹에서 요청 (앱을 삭제했거나 로그인할 수 없는 경우)

아래 내용을 담아 [담당자 이메일]로 보내 주세요.

  • 제목: [산돌이] 계정 삭제 요청
  • 가입 시 사용한 아이디 또는 이메일 주소
  • 카카오 로그인으로 가입했다면 카카오 계정 이메일

본인 확인을 위해 가입 이메일로 확인 메일을 보내드리며, 회신을 받은 날로부터 7일 이내에 삭제를 완료하고 결과를 알려드립니다.

삭제되는 데이터

  • 아이디, 이름, 이메일 주소, 생년월일 등 계정 정보 전부
  • 카카오 로그인 연동 정보
  • 기기에 저장된 로그인 토큰(앱에서 탈퇴한 경우 즉시 삭제)

보관되는 데이터

  • 서버 백업 사본: 삭제일로부터 최대 30일 이내에 완전히 삭제됩니다.
  • 접속 기록(IP 주소, 요청 시각): 「통신비밀보호법」에 따라 3개월간 보관 후 삭제됩니다. 이 기록만으로는 개인을 식별할 수 없습니다.

위치 정보는 서버에 저장되지 않으므로 삭제 대상이 없습니다.

자세한 내용은 개인정보처리방침을 참고하세요.
